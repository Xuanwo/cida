- 原文是你的语言时，面板上「翻译」后面写着要译成的外语，例如「翻译 English」。按 ⌘L 或点这几个字就能改写成任何语言，比如 日本語、한국어、文言文，按 ⏎ 立即重新翻译。设置里的「常用外语」因此移除，原来填过的外语会保留；⌥D 指着你的语言时也译成这一门。
- 翻译结果可以复制成图片：点「复制结果」右侧的 ⌄ 选「复制图片」，或按 ⇧⌘C。图上原文在上、译文在下，宽度按手机上看来排，可以直接贴进聊天。
- 很长的译文从开头读起：生成时不再自动滚到末尾，滚到正在写的最后一行才跟着往下走。上下还有没显示的文字时，结果栏的那一边会渐渐淡去。
- 按 ⌥D 后，这一段立即铺上一层呼吸的底色，表示正在翻译，模型慢时也分得清是没按上还是还在等；整窗翻译里等待翻译的新消息也一样。
- 夹着英文术语的中文，比如「把 README 里的 install 步骤改一下」，原处翻译按中文对待：⌥D 不再把它当外文，整窗翻译也不再把它送去翻译。
- 焦点停在输入框、选中的却是别处的文字时（例如在 Telegram 里选中一条消息），⌥A 也能把选中的文字带进面板。代价是没选中文字时按 ⌥A，个别应用会响一声提示音。
- 截图翻译保留原来的换行：聊天消息和列表逐行分开，不再连成一段；英文不再被识别成全角标点和错字。
