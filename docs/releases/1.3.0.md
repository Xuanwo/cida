- 辞达跟随系统的外观：Mac 用深色模式时，面板、设置、提示和原处的译文都换成深色，切换外观时已经打开的窗口也会随之变化。
- 每个快捷键都可以不设置：在设置的「快捷键」页录制时按 ⌫，把这个组合键让给别的应用。显示辞达和截图翻译不设置时，仍然可以从菜单栏使用；原处翻译不设置时会关闭，已翻译的内容恢复原文。
- 在读不到选中文字的应用里按 ⌥A，辞达会复制选中的文字带进面板，再把剪贴板恢复原样。
- ⌥D 指着一段你的语言时，也像面板一样译成常用外语；⌥⇧D 翻译整个窗口时，仍然只把外文译成你的语言。
- 检查更新移到设置的「通用」页，菜单栏只留下常用的几项。自动检查不再能关闭：辞达每天查一次新版本，安装仍然由你决定。
- 设置的「通用」页新增「反馈」：点「去反馈」会在浏览器里打开反馈表单，只预填版本信息，提交前可以看到并修改全部内容。
- 设置窗口切换页面时，标题和标签不再上下跳动；提示小条的阴影不再被截成一块灰色方框。
