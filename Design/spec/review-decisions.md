## 共同方向

- 服务于已有 AI agent 的用户；配置通过复制提示词交给 agent 完成，不增加手工配置表单。
- 保留纸面、衬线正文与绿色强调的视觉语言。以精确状态、操作的可发现性和一致性改善体验。
- 03–05 的右侧槽位只放一个下一步动作：执行、停止、复制、重新生成或错误对应的恢复动作。按钮与标注的快捷键执行同一个动作。
- 新结果的复制在槽位；旧结果、部分输出的复制跟随结果，放在纸面标题行。保留文字和图片两种复制方式，以及原有的选中文字优先规则。
- 配置诊断交给 agent。用户界面显示服务身份、状态和下一步，只有改变用户操作的信息才单独说明；不显示状态码或服务商原文。尚未检查和旧结果用中性色，不用绿色暗示成功。
- 02–08 沿用当前 token；09 的颜色和字号单独确认。原型的模拟输出和事件不能视为原生实现证据。

## 01 初次连接：已确认

最终行为以[生命周期 §三](lifecycle.md#三第一次使用)为准：独立欢迎页、保留带入原文、收到完整配置后提供可跳过的试译，不自动发送请求。正文明确「在设置里复制配置提示词」，主按钮保留「连接模型服务 ⏎」和已有绿色样式。

验收覆盖未配置、已带入原文、收到配置后的试译与跳过、后续已配置启动，以及浅色和深色欢迎页。配置完整不等同于连接检查通过。

2026-10-06 验证：构建、314 项单元测试、网站构建及两条 Tart 原生旅程通过。静态效果见 `Design/QACurrent/comparison-lifecycle-welcome*.png` 与 `comparison-dark-lifecycle-welcome.png`；行为覆盖与边界见 [Design QA](../../docs/design-qa.md#first-connection)。

## 02 Agent 配置：已确认

最终行为以[配置 §四–五](configuration.md#四设置里的模型页)为准：当前状态、服务身份和一个复制入口。失败只显示「检查未通过」与「复制配置提示词，交给 AI 助手继续检查。」；删除技术细节、状态码、服务商原文和检查来源。

提示词按初次配置、继续配置、调整、继续检查生成。agent 通过 CLI 自行读取诊断、修改、验证，确需用户提供信息、授权或处理账户问题时再询问，不盲目重复失败。配置齐全即可使用，检查可选；旧检查仅在配置变化时失效。

复制后不显示虚构的 agent 工作状态。代价是用户在 agent 询问前不知道是否需要补充 Key 或处理账户问题；界面只在确认缺 Key 时直接点名。

## 03 执行与语言：待确认

- 在空闲槽位新增可点击的「翻译 ⏎」等执行按钮，用现有描边样式；原文为空时禁用。
- 外语保留在选中的翻译段内，显示「翻译成 English」；沿用现有显示条件与方向规则，悬停下划线和焦点提示编辑能力，不添加伪下拉图标。
- 编辑语言时，输入框的 Enter 与槽位按钮使用同一个提交动作，按条件显示「确定」或「确定并翻译」；Esc 放弃修改。
- 代价：槽位在编辑时会换标签；设置最小宽度减少跳动。描边按钮的可发现性尚无用户测试。

## 04 旧结果：待确认

- 保持旧正文正常可读，标题注明「上次翻译 · 原文已修改」等生成上下文和过期原因，不新增历史记录。
- 槽位显示「重新生成 ⏎」；切换动作后改为新动作名，例如「改进 ⏎」。
- 复制放在旧结果标题行，支持复制文字和图片；图片使用生成该结果时的原文。
- 代价：复制按钮会从槽位移到结果上下文中；快捷键保留原有复制语义，不能放进重新生成按钮的菜单。

## 05 失败恢复：待确认

- 保留已输出文字，不静默重试。超时、断网、429、安全连接失败、未知错误提供「重试 ⏎」；401/403/404 提供「模型设置 ⌘,」。
- 配置类错误时 Enter 不执行隐藏重试，也不打开设置；配置更新后才出现「重试 ⏎」。改变原文或动作后按新请求处理，原失败注明属于上次请求。
- 429 不臆测限流或额度耗尽，不伪造倒计时；安全连接失败不提供跳过校验。
- 部分输出只标一次未完成，保留文字和图片复制。文字复制保持正文；图片随正文标注「未完成 · 请求中断」或「未完成 · 生成时已停止」，完整结果不加标注。
- 代价：配置错误时 Enter 暂不执行，需要就地说明原因；未完成的分享图新增状态标注，有意改变这类图片只含正文的约定。

## 06 动作试运行：待确认

- 未编辑也能用已保存提示词直接试运行，沿用固定中文工作沟通样例；不开放任意测试文本、多份草稿或历史管理。
- 保留纸面编辑器、现有字号与行距，以及编辑 ⌘E、完成 ⌘↵、停止 ⌘.；非编辑时 ⌘↵ 用于试运行。
- 编辑时保留上次预览作参照，明确它对应已保存版本；增加放弃修改。
- 补齐运行中、已停止、试运行失败、保存成功但预览失败。保存与试运行结果分别反馈。
- 代价：编辑时保留参照结果会增加窗口高度。

## 07 快捷键与权限：待确认

- 保留四项入口及自定义键位、未设置、恢复默认、录制流程和常驻权限状态。
- 每行可展开和收起用法卡，说明任务过程、所需权限和其他共用这项权限的能力。展示随用户配置变化的键位。
- 区分可点击的录制键帽与说明文字里的键位。用法卡和权限组里的授权入口共享同一状态来源。
- 按需申请权限是已有行为，继续保留；新增的是更容易理解的任务示例和入口说明。

## 08 更新操作：待确认

- 用命令按钮替换分段选择，准确表达每次点击的结果：发现更新时叫「下载更新」，准备完成后再提供安装时机。
- 保留标题中的下载百分比与流式光标，不加重复进度条。补齐检查中、只读位置、已是最新和失败状态；跳过版本为次要文字按钮。
- 准备完成后推荐 Enter 默认「退出时安装」；「立即重启」仍可点击或通过 Tab、Space 执行。有进行中的请求时明确说明重启会停止它。
- 代价：立即重启多一次显式操作；默认动作保持稳定，不随隐藏的请求状态切换，不额外增加确认弹窗。

## 09 字色与尺度：待确认

- 用同尺寸、同内容的实际界面比较浅深色效果，包括动作编辑、失败说明、快捷键权限、text-control 与焦点；不变的值注明保持。
- 11 / 11.5 的小字号建议统一到 12；加强 secondary、tertiary、hint 和深色 accent，保留纸面、正文、圆角、浅色 accent 和焦点描边。
- 建议 secondary 浅色 #5E5E57、深色 #B0AFA6；tertiary 与 hint 浅色 #707069、深色 #9C9C94；深色 accent #6FAA8A。tertiary 与 hint 收敛到同一色值，不为区分角色强加灰阶。
- 必要文字在实际相关背景中最不利的对比度至少 4.5:1；原生落地时同步 CSS / Swift token 并重新验证，不把原型计算当作完整可访问性认证。
