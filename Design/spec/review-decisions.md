## 共同方向

- 服务于已有 AI agent 的用户；配置通过复制提示词交给 agent 完成，不增加手工配置表单。
- 保留纸面、衬线正文与绿色强调的视觉语言。以精确状态、操作的可发现性和一致性改善体验。
- 控制条操作当前输入：执行、重新执行或停止；复制始终在结果标题行，反馈也留在结果区。按钮与标注的快捷键执行同一个动作。
- 保留文字和图片两种复制方式，以及选中文字优先规则。旧结果和图片中的原文总是对应同一次执行。
- 配置诊断交给 agent。用户界面显示服务身份、状态和下一步，只有改变用户操作的信息才单独说明；不显示状态码或服务商原文。尚未检查和旧结果用中性色，不用绿色暗示成功。
- 09 按确认稿调整文字颜色层级，保留字号、品牌色与布局。原型的模拟输出和事件不能视为原生实现证据。

验收覆盖未配置、已带入原文、收到配置后的试译与跳过、后续已配置启动，以及浅色和深色欢迎页。配置完整不等同于连接检查通过。

## 02 Agent 配置：已确认

最终行为以[配置 §四–五](configuration.md#四设置里的模型页)为准：当前状态、服务身份和一个复制入口。失败只显示「检查未通过」与「复制配置提示词，交给 AI 助手继续检查。」；删除技术细节、状态码、服务商原文和检查来源。

提示词按初次配置、继续配置、调整、继续检查生成。agent 通过 CLI 自行读取诊断、修改、验证，确需用户提供信息、授权或处理账户问题时再询问，不盲目重复失败。配置齐全即可使用，检查可选；旧检查仅在配置变化时失效。

复制后不显示虚构的 agent 工作状态。代价是用户在 agent 询问前不知道是否需要补充 Key 或处理账户问题；界面只在确认缺 Key 时直接点名。

## 03 执行与语言：已确认

- 在空闲槽位统一显示可点击的「执行 ⏎」，用现有描边样式；原文为空时禁用。当前动作由左侧选中项表达，自定义动作的名称不影响执行按钮宽度。
- 外语保留在选中的翻译段内，显示「翻译成 English」；沿用现有显示条件与方向规则，悬停下划线和焦点提示编辑能力，不添加伪下拉图标。
- 编辑语言时不放确认按钮，槽位显示「⏎ 确定 · Esc 取消」；语言改变且原文非空时明确写「⏎ 确定并重新翻译 · Esc 取消」。Enter 保存并按条件重新翻译；Esc 或失焦取消，Tab 不切换，结束后焦点回原文。输入法组字优先，期间提示「输入法组字中 · ⏎ 选词」，结束后恢复确认提示。
- 执行与停止最小宽度 92；提示不重复语言名。代价：确认依赖键盘，指针与辅助控制没有可点的确认入口；误点别处会丢弃语言草稿。描边按钮与悬停提示的可发现性尚无用户测试。

## 04 旧结果：已确认

- 结果标题行固定显示「结果」与无边框的「复制 ⌘C ⌄」。原文或动作变化后只把标题改为「上次结果 · 待更新」，旧正文保持正常墨色；恢复生成时的原文与动作即取消待更新。
- 控制条始终执行当前输入，同一动作显示「重新执行 ⏎」，另一动作显示「执行 ⏎」，运行中显示「停止 ⌘.」。不把自定义动作名放进按钮，外语编辑确认保留 03 的优先级。
- 清空原文时禁用执行，旧结果仍可复制；编辑不自动发请求。新执行立即替换旧结果，不增加历史记录。
- 复制及其反馈始终留在标题行，支持旧结果文字与图片，图片使用生成时的原文。执行中复制入口保留但禁用，沿用请求结束后才可复制的契约。
- 代价：所有结果增加一行固定标题，长结果可见正文相应减少；短结果打开复制菜单时适度扩展面板高度。

## 05 失败恢复：已确认并实现

- 保留已输出文字，不静默重试。超时、断网、429、安全连接失败、未知错误提供「重试 ⏎」；401/403/404 提供「模型设置 ⌘,」。
- 配置类错误时 Enter 不执行隐藏重试，也不打开设置；配置更新后才出现「重试 ⏎」。改变原文或动作后按新请求处理，原失败注明属于上次请求。
- 长度超限由辞达自动分段、缩小片段并按顺序完成，用户无需缩短或分段。自定义动作合并为一份结果，取消终止后续片段；普通失败不自动重试。429 不臆测限流或额度耗尽，不伪造倒计时；安全连接失败不提供跳过校验。
- 配置提示词可以附当前配置对应的安全失败类别，说明来源是面板请求；不附原文、输出、服务商原文或凭据，不把面板失败当成一次连接检查。
- 部分输出只标一次未完成，保留文字和图片复制。文字复制保持正文；图片随正文标注「未完成 · 请求中断」或「未完成 · 生成时已停止」，完整结果不加标注。
- 代价：配置错误时 Enter 暂不执行，需要就地说明原因；未完成的分享图新增状态标注，有意改变这类图片只含正文的约定。

## 06 动作试运行：已确认并实现

- 未编辑也能用已保存提示词直接试运行，沿用固定中文工作沟通样例；不开放任意测试文本、多份草稿或历史管理。
- 保留纸面编辑器、现有字号与行距，以及编辑 ⌘E、完成 ⌘↵、停止 ⌘.；非编辑时 ⌘↵ 用于试运行。
- 编辑时保留上次预览作参照，明确它对应已保存版本；增加放弃修改。
- 补齐运行中、已停止、试运行失败、保存成功但试运行失败。保存与试运行结果分别反馈；配置失败沿用 05 的 agent 恢复入口。
- 代价：编辑时保留参照结果会增加窗口高度。

## 07 快捷键与权限：已确认并实现

- 保留四行快捷键与常驻权限组，以及录制、未设置、恢复默认、冲突反馈和按需授权。
- 用行内说明表达用途：显示辞达会带入选区并执行首项动作；原处翻译说明段落、再次按键换回和加 ⇧ 整窗；改进并替换说明写回原处。
- 说明使用右侧控件前的剩余宽度，保留 24pt 间距和现有行高、字号、视觉语言。
- 辅助功能说明共用权限的三项能力；屏幕录制说明截图翻译和原处翻译跟随滚动。未授权时原处翻译仍可使用，不额外申请屏幕录制。
- 不增加用法展开卡、独立指南、模拟演示或权限跳转。

## 08 更新操作：已确认并实现

- 右侧命令按钮代替分段选择；Tab 移动焦点，空格执行聚焦按钮，⏎ 始终执行最右侧主操作。
- 「安装并重启」只确认一次，下载、校验后直接安装并重新打开。
- 下载时离开面板则继续下载，但撤销自动重启意图；设置保留「安装…」，回到「已下载」后再次明确安装。
- 已下载沿用「稍后 / 安装并重启」，删除「立即重启 / 退出时安装」和二次确认；安装时隐藏控制条，说明会在菜单栏重新打开。
- 保留 Sparkle、签名校验、通道、停止、重试与只读位置说明。

## 09 字色与尺度：已确认

最终规则见[外观 §四](appearance.md#四小字的颜色层级)，颜色与字号以 CSS / Swift token 为准。

- 问题是角色分配：必须读或点的小字用了 `text-tertiary`。设置每行说明与录制、冲突反馈，更新面板的「跳过这个版本」，改外语时的确认提示，动作编辑的「放弃修改 · 恢复默认 · 删除动作」、提示词状态、参照标签与「拖动排序 · 首项默认」改用 `text-secondary`。
- 浅色 `text-secondary` 从 #8A8A83 加深到 #74746D：设置底 4.50:1、surface 4.71:1，纸面 4.35:1、surface-dim 4.27:1（后两处未达 4.5:1）。深色 `text-secondary` 不变。
- `text-tertiary` 色值不变，用于冗余键位符号、分隔点、占位、版本与模型名补充、小标题和禁用。`hint` 并入 `text-tertiary`，删除独立 token。
- 字号、`accent` 与 `accent-soft`、1pt 焦点线保持。不再建议小字统一到 12、全局加深 tertiary 与 hint 或改深色 accent。
- 对比度是色值计算，不是无障碍认证；验收使用原生浅深色截图复核观感，并在 Tart 中检查键盘焦点。
