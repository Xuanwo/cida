# 设置

2026-09-23 在 Proposal 上确认，取代 Settings 单板与 Settings Row 组件。状态见 [`boards/settings-states.html`](../boards/settings-states.html)。

## 一、窗口

- 标准标题栏窗口（⌘, 或菜单栏「设置…」），宽 560 固定；高度随内容，不滚动；`bg` 底色，内容左右内缩 28（`space-window-x`）。
- 三组，按用户的问题分组：模型（用什么模型）→ 提示词（怎么翻 / 怎么改）→ 唤起（怎么唤起）。组标题 12 semibold `text-control`；组间 1px `border` 分隔；行 = 标签列 120 + 24 间距 + 控件列铺满；标签 13.5 `text-primary`，说明 11.5 `text-tertiary`；行上下 padding 9。
- 全部自动保存（250ms 合并），没有保存 / 取消按钮。

## 二、模型

- 服务商是菜单，每一项是预设：预设 = 端点 + 建议模型 + 是否需要 Key；列表末尾固定「自定义（OpenAI 兼容）」。当前预设：DeepSeek、OpenAI、Moonshot、智谱 GLM。加服务商只加一行预设，界面不变。
- 选预设时菜单下方一行说明写实际请求的域名（如 `api.deepseek.com · Chat Completions`），不显示端点输入；选自定义时出现「端点」行（`font-mono`，铺满，聚焦 1.5px accent 描边）。
- 模型：预设 → 建议模型菜单，最后一项「其他…」把这一行换成输入框；自定义 → 输入框。切换服务商时模型回到该预设第一项。
- API Key：遮罩输入框铺满（`font-mono`），说明「只存本机钥匙串」；自定义且端点为 localhost / 127.0.0.1 / ::1 时占位「本地端点可留空」。
- 就绪行（组末尾，6pt 圆点 + 12 `text-secondary`，本地推导不联网）：已就绪（accent 点）/ 还差 API Key（`text-tertiary` 点）/ 本地端点 · 无需 API Key（accent 点）/ 端点无效（`text-tertiary` 点）。

## 三、提示词

- 折叠：标签 + 首句预览（11.5 `text-tertiary`，单行截断）+「编辑」边框按钮（`surface`，`border`，`radius-card`）。
- 展开：标签 +「恢复默认」文字按钮，编辑区为纸面（`surface-paper`，`radius-card` 8，padding 14，Inter 13 / 1.6 `text-ink`，聚焦 1.5px accent 描边），下方说明「自动保存 · 目标语言与任务由应用传入，不必写占位符」。
- 同一时刻只展开一个；展开与收起随内容改变窗口高度。

## 四、唤起

- 全局快捷键：键帽芯片（`surface-dim`，`radius-chip`，12 medium `text-secondary`）是一个按钮，显示当前组合，默认「⌥ Space」；说明「在任何应用里显示辞达」。点击进入录制：芯片改为 `surface` 底、1.5px accent 描边、`text-tertiary`「按下新组合…」，说明变为「Esc 取消」；按下带 ⌘/⌥/⌃ 的组合立即保存并重新注册，Esc 或失焦取消；按下不带这些修饰键的按键不结束录制，说明改为「要带 ⌘、⌥ 或 ⌃」。注册失败（被系统或其他应用占用）保留原组合，说明变为「这个组合已被占用，换一个」。组合不是默认值时，芯片左侧出现「恢复默认」文字按钮（12 medium `text-secondary`）。菜单栏「显示辞达」的快捷键跟随该组合。
- 截图翻译：第二个快捷键芯片，默认「⌥ S」，录制、恢复默认、占用提示与全局快捷键相同；两个快捷键不能相同。说明：已授权「框选屏幕文字并翻译」，未授权「需要屏幕录制权限」并在芯片左侧出现「去授权」边框按钮（弹出系统授权并打开「隐私与安全性 › 屏幕录制」）。授权后 macOS 可能要求重新打开辞达。录制任一快捷键时两个全局快捷键都暂停，按下的组合只交给录制。
- 选中文字：Option-Space 带入选区需要辅助功能权限。未授权：说明「需要辅助功能权限」，右侧「去授权」边框按钮（同「编辑」），点击弹出系统授权提示；已授权：说明「唤起时带入并翻译」，右侧「已开启」（12 medium `text-secondary`）。状态在窗口成为 key 与系统辅助功能列表变化时重新读取，不需要重启；没有开关，取消授权即关闭。
- 开机启动：开关（accent 开 / `toggle-off` 关），失败时系统警告框说明。
- 页脚居中：辞达（`font-brand` 12 semibold，字距 2，`text-secondary`）+「1.0 · 辞达而已矣」（caption，`text-tertiary`）。

## 五、强调色

只出现在：菜单当前项的 ✓、就绪点、聚焦描边、开关打开。
