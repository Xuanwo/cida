# 生命周期

2026-09-25 确认：从下载、第一次打开到之后每次升级，辞达要对用户说的话都用主面板说，不弹系统风格的窗口。状态见 [`boards/lifecycle.html`](../boards/lifecycle.html)，面板本身见 `spec/panel.md`，更新的检查与通道见 `spec/updates.md`。

## 一、面板里的「辞达说」

- 形态与主面板完全相同：宽 800、顶边在活动屏幕可见高度 20%、`radius-panel` 14、同样的描边与阴影，出现与隐藏同主面板。
- 三栏各司其职：
  - 原文栏：一句陈述（Inter 16 `text-primary`，不可编辑、没有光标），说明现在是什么情况。
  - 控制条：左侧分段控件列出可选的做法，Tab 切换、⏎ 执行，默认选中第一项；右侧槽位放进行中的状态或「停止 ⌘.」。
  - 结果栏：纸面衬线正文（`surface-paper`，同结果栏排版），写为什么、会发生什么，或者新版本的更新说明。
- 进行中（移动、下载、安装）分段控件降为 45% 不可切换，结果栏末尾是流式光标；出错时结果栏末尾一行说明「…失败：<原因> · ⏎ 重试」，与翻译出错相同。
- ⎋、点击面板外、切换应用都等于最后一项（暂不 / 稍后），面板隐藏。之后按 ⌥Space 回到平常的翻译面板，原文与结果原样保留；「辞达说」不会盖掉用户的内容。

## 二、安装包

- 下载链接（README、官网）指向 `https://cida-releases.xuanwo.io/latest/Cida.dmg`；GitHub Release 附同一个 DMG 与它的 SHA-256。
- DMG 打开是一个 600 × 400 的 Finder 窗口：`surface-paper` 纸底，左边辞达图标、右边「应用程序」，中间一条 `text-tertiary` 细箭头；上方衬线一句「把辞达拖进「应用程序」」，下方 caption「之后从启动台或聚焦搜索打开」。没有工具栏与侧栏。
- DMG 与其中的应用都经过 Developer ID 签名与 Apple 公证。Sparkle 更新继续用 zip（`releases/<版本>-<构建>/`），DMG 只给第一次安装。

## 三、移到「应用程序」

- 每次由用户打开（见 §五），若应用不在 `/Applications` 或 `~/Applications`（在 DMG 里、在「下载」里、被系统挪到随机只读路径），先显示移动面板，不显示欢迎与更新：
  - 原文栏「辞达正从磁盘映像运行」或「辞达正从「下载」运行」（其他位置写所在文件夹名）。
  - 分段「移到「应用程序」」「暂不」。
  - 结果栏「放进「应用程序」后，辞达才能自己更新、开机启动。移好后会重新打开，原来的这份会被移除。」
- 「应用程序」里已有辞达时，第一项改为「替换并打开」，结果栏说明「「应用程序」里的辞达 <版本> 会移到废纸篓」。
- 执行：复制到 `/Applications`（没有写权限时退到 `~/Applications`），去掉隔离属性，从新位置重新打开，退出当前这份；来源是 DMG 时推出磁盘映像，来源是「下载」时把原件移到废纸篓。进行中右侧槽位「正在移动…」。
- 失败（空间不足、没有权限）：说明「移动失败：<原因> · ⏎ 重试」，仍可选「暂不」。
- 「暂不」只对这一次打开有效，下次由用户打开时再问。开发构建、自动化与 E2E 运行不检查位置。

## 四、第一次使用

- 模型还没就绪（设置里就绪行不是「已就绪」「本地端点 · 无需 API Key」）时，空态面板的结果栏是欢迎：
  - 衬线正文「辞达帮你在任何应用里翻译和改进文字。先选一个模型服务、填入 API Key，就可以开始。」，下一行 caption「⌥Space 随时唤起 · ⌥S 截图翻译 · 辞达住在菜单栏」（快捷键跟随设置）。
  - 右侧槽位「打开设置 ⌘,」。原文栏照常可输入；此时 ⏎ 不发请求，结果栏说明「还差 API Key · ⌘, 打开设置」。
- 模型就绪后欢迎消失，面板回到 `spec/panel.md` 的空态。

## 五、启动时是否出现

- 用户打开（Finder、启动台、聚焦搜索、再次打开已在运行的辞达）：出现面板。按优先级：移动面板 → 可安装的更新（启动时的定时检查发现新版本） → 平常面板（没就绪时带欢迎）。
- 开机启动、更新后自动重新打开：不出现面板，只在菜单栏。

## 六、更新

发现新版本（用户点「检查更新…」、菜单「安装新版本 <版本>…」、设置「安装…」，或启动时发现）：

- 检查中（仅用户主动检查）：原文栏「正在检查更新…」，结果栏只有流式光标，右侧「停止 ⌘.」。
- 发现新版本：
  - 原文栏「辞达 <新版本> 可以安装 · 当前 <版本>」。
  - 分段「安装并重启」「稍后」「跳过这个版本」。
  - 结果栏是这个版本的更新说明：发版时手写的中文，逐条一行，衬线正文，超过上限时内部滚动。
- 下载与校验：
  - 原文栏「正在下载辞达 <新版本> · <百分比>」，校验与解压时为「正在校验…」。
  - 右侧「停止 ⌘.」，停止即取消这次更新。
  - 结果栏保留更新说明，末尾流式光标。
- 准备好：原文栏「辞达 <新版本> 已准备好」，分段「立即重启」「退出时安装」。
- 安装：原文栏「正在安装…」，辞达退出并由新版本重新打开（不出现面板，见 §五）。
- 已是最新（仅用户主动检查）：原文栏「辞达 <版本> 已是最新版本」，分段只有「好」。
- 出错：结果栏末尾「检查更新失败：<原因> · ⏎ 重试」或「下载失败：…」「安装失败：…」。
- 后台定时检查发现新版本且不在启动时：不弹面板、不抢焦点，只改菜单项与设置「更新」一行（`spec/updates.md` §二）；点其中任一处出现「发现新版本」面板。

## 七、更新说明

- 每个版本在 `docs/releases/<版本>.md` 写给用户看的中文说明，一条一行，以「- 」开头，写用户能感到的变化，不写提交信息。候选版本用它将要成为的版本的说明。
- 发版流程读取这份文件写进更新清单；文件不存在时发版失败。

## 八、卸载

- 退出辞达（菜单「退出辞达」），把「应用程序」里的辞达移到废纸篓。
- 想清掉全部痕迹：「钥匙串访问」里名为 `com.xuanwo.Cida` 的 API Key 条目，与 `~/Library/Preferences/com.xuanwo.Cida.plist`。README 写明这两处。
