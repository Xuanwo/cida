# 面板模型

2026-09-22 在 Proposal C 上确认方向，取代历史时间线与固定窗口。状态见 [`boards/panel-states.html`](../boards/panel-states.html)，截图框选见 [`boards/capture.html`](../boards/capture.html)，量值以 [`boards/tokens.css`](../boards/tokens.css) 为准。

## 一、面板

- Cida 是菜单栏常驻应用，没有 Dock 图标；主界面是无标题栏的浮动面板（nonactivating panel），不激活应用，原应用保持前台。Settings 仍是标准窗口（⌘,），也可从菜单栏图标进入；当前模型显示在菜单栏菜单里，不占面板。
- 唤起：Option-Space；出现在活动屏幕（前台应用 key window 所在屏幕，否则鼠标所在屏幕）水平居中、顶边在可见高度 20% 处；120ms（`motion-icon-in-ms`）淡入。每次唤起原文栏都拿到键盘焦点。
- 带入选区（2026-09-24 决定）：Option-Space 唤起前读取前台应用焦点控件的选中文字（辅助功能 API，`kAXSelectedText`）。读到的文字（去掉首尾空白）与上次带入的不同，就替换原文（全选）、动作回到「翻译」并立即生成，正在进行的请求被取代；与上次带入的相同则按「再次唤起」原样出现，不重复请求也不覆盖在面板里改过的原文。没有选区、焦点是密码框、前台是辞达自己、读取超过 150ms、或未授权辅助功能时，都按没有选区处理，且清空「上次带入」，之后重新选中同一段仍会带入。不模拟 ⌘C、不读剪贴板：读不到选区的应用（部分 Electron / Chrome 页面）照旧手动 ⌘C ⌘V。只有全局快捷键带入；菜单栏「显示辞达」不读选区。授权入口在 Settings「唤起」组。
- 截图翻译（2026-09-25 决定）：第二个可录制的全局快捷键，默认 ⌥S。按下时先隐藏面板，冻结鼠标所在的整块屏幕，再在冻结画面上淡入一层纸雾（亮屏 `surface-paper` 72%，暗屏 `text-ink` 45%），屏幕上方 20% 一枚带「辞达」字标的提示胶囊，选区碰到胶囊时胶囊淡出；拖出的选区被托起成一张纸（圆角 8、面板同款阴影与描边，暗屏描边 `#FFFFFF24`），光标为十字；只在这一块屏幕内框选。Esc、右键或只单击不拖动都取消，面板不出现。松开后从冻结画面裁出选区，本地识别文字（Vision，简体中文与英文，不上传图片），按行拼回段落：同一段内英文补空格、去掉行尾连字符，中文直接相连，行距明显变大处分段。识别到文字：原文换成识别结果（全选），动作回到「翻译」并立即生成，取代正在进行的请求；没有文字：原文清空，结果栏只显示「截图里没有识别到文字」，不发请求。需要屏幕录制权限；未授权时按下不截屏，只请求授权（首次弹出系统提示，并打开「隐私与安全性 › 屏幕录制」）。截图进行中两个快捷键都不响应。macOS 每月会再次确认一次该权限，无法避免。应用启动后在后台预热一次识别模型（首次识别约 13 秒，之后约 0.4 秒）。
- 隐藏：Escape、再按 Option-Space、点击面板外、切换应用；立即隐藏，不做动画。隐藏不丢任何状态：原文、结果、主动词下次原样出现。
- 宽度固定 800，内容左右内缩 28（`space-window-x`）；高度由内容决定，顶边固定只向下生长，上限为屏幕可见高度 70%。

## 二、结构（自上而下）

- 原文栏：可编辑，`surface` 底色，padding 18/28；高度随行数变化，上限为屏幕可见高度 30%，超出后内部滚动、保持光标可见；不显示字数（2026-09-23 删除，对输入没有帮助）。
- 滚动条：两栏都用系统 overlay scroller（2026-09-23 决定，取代 4pt 自绘指示条）：滚动时出现、静止后淡出、悬停变宽；固定 overlay 样式，不随系统「显示滚动条」偏好或外接鼠标切成带轨道的 legacy 滚动条（那会常驻显示并把文字列压窄 16pt）；静态设计稿里不画滚动条。结果栏的滚动视图与原文栏一样贯通 800 宽，文字在内部缩进 28，所以两条滚动条贴着同一条面板右缘。
- 控制条：`surface` 底色，上下 1px `border`，padding 10/28。左侧动作选择（翻译 / 改进）与 Tab 提示；右侧一个槽位、一个按钮、三个阶段：空态与输入中为空，生成中「停止 ⌘.」，完成或已停止后「复制结果 ⌘C」。没有发送按钮、语言对、模型芯片和状态文本。
- 结果栏：`surface-paper` 底色，padding 22/28，只有结果正文和一行可选的说明（已修改 / 已停止 / 出错 / 截图未识别到文字）；生成期间跟随尾部，用户上滚即解除，滚回底部恢复。
- 高度变化：所有栏高与面板高度变化用 150ms（`motion-height-ms`）ease-out 过渡；流式中每换一行面板 +26pt；reduced motion 时不做过渡。两栏都到上限时原文栏取 30%，结果栏取剩余。

## 三、动作

- 控制条左侧是动作选择（分段控件）：「翻译」「改进」二选一，Tab 切换，⏎ 执行当前动作；没有鼠标用的发送按钮，执行只靠 ⏎。每次唤起面板时动作回到默认「翻译」。
- 分段控件固定显示「翻译」「改进」，不显示语言方向：源语言在后台自动检测，目标语言取中英语言对里的另一种；改进的输出语言跟随原文。
- 原文为空时 ⏎ 无效，动作仍可切换。
- 执行中：右侧槽位 150ms（`motion-icon-swap-ms`）淡入「停止 ⌘.」，动作选择降为 45% 不可切换。完成后停止交叉淡化为「复制结果」，动作选择复原；再按 ⏎ 重新生成，Tab 换动作后 ⏎ 用另一动作处理同一段原文。

## 四、状态

见 [`boards/panel-states.html`](../boards/panel-states.html)。

- 空态 → 输入中 → 生成中 → 完成 → 已复制；分支：已修改、已停止、出错；再次唤起原文全选；带入选区与截图识别到文字直接进入生成中；截图没有文字见 ⑪。
- 「复制结果」只在存在可复制结果（完成或已停止）时出现；点击或 ⌘C（原文与结果都无选区时；有选区则复制选区，复制原文即在原文栏选中后 ⌘C）→「✓ 已复制」`accent-soft` 底，800ms（`motion-copied-hold-ms`）后复原。⌘C 在有原生选区时保持系统语义。
- 已修改：原文或动作与生成时不同 → 结果降为 `text-secondary`，结果栏末尾说明「原文已修改 · ⏎ 重新生成」；不自动重新请求。
- 已停止 / 出错：已输出文字保留；结果栏末尾说明「已停止 · ⏎ 重新生成」或「请求失败：… ⏎ 重试」（出错说明附带模型名）；不弹 alert。
- 再次唤起：原文全选，直接输入或 ⌘V 即替换，方向键取消选择；结果保留直到下一次提交。

## 五、键位

Option-Space 显示 / 隐藏（有新选区时带入并翻译）· ⌥S 截图翻译 · Escape 隐藏 · ⏎ 执行当前动作 · Tab 切换动作 · Shift-⏎ 换行 · ⌘C 复制结果 · ⌘. 停止 · ⌘, 设置。

## 六、不做的事

- 不持久化记录，应用重启后为空态。
- 不提供钉住、不允许拖动改变大小或位置。
- 面板上不切换目标语言和模型，这两项属于 Settings。

## 七、视觉

- 面板：`surface` 白底、`radius-panel` 14、1px `#00000012` 描边、双层阴影（0/2/6 8% + 0/28/72 19%）。原文栏与控制条同为 `surface`，结果栏为 `surface-paper` 暖纸底，用材质而不是线条区分「输入」与「输出」。
- 字体分工是这套视觉的核心：原文是 Inter 16 / 1.6 的输入感；结果是排好的正文 — 拉丁文 Source Serif 4 17.5 / 1.65，中文 Noto Serif SC 17 / 1.85，墨色 `text-ink`；实现侧用 Source Serif 4 + Noto Serif SC 的字体级联处理混排。
- accent 只出现在三处：分段控件的选中项文字、流式光标、已复制反馈。控制条没有填充色的按钮；「复制结果 / 停止」是白底描边的 pill，文字 `text-control`。
