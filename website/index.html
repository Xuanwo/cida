六种用法

快捷键都是默认值，可以在设置里重新录制。

翻译选中的文字

⌥ A

面板带着选中的文字出现，执行首项动作，默认是翻译。翻译时，其他语言都译成你的语言；你的语言译成「翻译」旁边写着的外语，默认英文，要换就在那里直接写。两者都可以写成任何语言、方言或文体。

改进并替换

⌥ F

选中正在写的文字，直接润色并替换，语言不变。在原应用按 ⌘Z 可以撤销；生成期间编辑或切换应用时，结果保留供你查看和复制。

用自己的方式处理文字

⌘ ,

在设置的「动作」页写好名字和提示词，用当前模型预览样例。精简、提取待办或改成邮件，都可以成为动作；拖到第一项，就成为面板的默认动作。

翻译屏幕上的文字

⌥ S

图片、视频和选不中的界面，框出要翻译的部分。辞达在本机识别文字，再交给模型翻译。

在原处读一段

⌥ D

指着一段外文按下快捷键，这一段就地换成译文，前后还是原文，带着上下文读；再按一次换回。

翻译整个窗口

⌥ ⇧ D

连续读 Slack 频道或一篇长文时用。新内容出现就翻译，再按一次停止；代码保持原样，点击和滚动照常落到原来的应用。

三步装好

  1. 打开 Cida.dmg

    把辞达拖进「应用程序」再打开。安装包经过 Developer ID 签名和 Apple 公证；辞达只在菜单栏显示图标，不占用 Dock。

  2. 让 AI 助手配置模型

    按 ⌘ , 打开设置，点「复制配置提示词」，交给 Claude Code、Codex 等助手。它会问你用哪家服务，写好配置后自己检查一遍。

  3. 把 API Key 存进钥匙串

    Key 不经过助手：它请你复制 Key 后运行一条命令，Key 直接存进钥匙串。在本机运行的模型不需要 Key。

文字只去你选的地方

  • API Key 只存在 macOS 的钥匙串里。
  • 不保存历史记录，不收集任何数据；文字处理和动作预览的请求只发往你选择的服务商。
  • 截图在本机用 Apple 的 Vision 识别，图片不会离开你的 Mac。原处翻译通过辅助功能读取文字；已有屏幕录制权限时，还会在本机内存中处理源窗口的画面，让译文跟随滚动，画面不保存、不上传。未授权时，滚动中的译文暂时隐去，停下后重新定位。
