五种用法

快捷键都是默认值，可以在设置里重新录制。

翻译选中的文字

⌥ A

面板带着选中的文字出现，译文随即流出。你的语言译成常用外语，其他语言都译成你的语言；两者默认是简体中文和英文，可以写成任何语言、方言或文体。

润色

Tab ⏎

在面板里按 Tab 切到「改进」，再按 Return。润色后的文字保持原来的语言，复制回去就能用。

翻译屏幕上的文字

⌥ S

图片、视频和选不中的界面，框出要翻译的部分。辞达在本机识别文字，再交给模型翻译。

在原处读一段

⌥ D

指着一段外文按下快捷键，这一段就地换成译文，前后还是原文，带着上下文读；再按一次换回。

翻译整个窗口

⌥ ⇧ D

连续读 Slack 频道或一篇长文时用。新内容出现就翻译，再按一次停止；代码保持原样，点击和滚动照常落到原来的应用。

三步装好

  1. 打开 Cida.dmg

    把辞达拖进「应用程序」再打开。安装包经过 Developer ID 签名和 Apple 公证；辞达只在菜单栏显示图标，不占用 Dock。

  2. 让 AI 助手配置模型

    按 ⌘ , 打开设置，点「复制配置提示词」，交给 Claude Code、Codex 等助手。它会问你用哪家服务，写好配置后自己检查一遍。

  3. 把 API Key 存进钥匙串

    Key 不经过助手：它请你复制 Key 后运行一条命令，Key 直接存进钥匙串。在本机运行的模型不需要 Key。

可选权限开启后不开启时
辅助功能唤出面板时自动带入选中的文字；可以原处翻译先 ⌘C，再在面板里 ⌘V；原处翻译不可用
屏幕录制可以翻译屏幕上的文字截图翻译不可用

文字只去你选的地方

  • API Key 只存在 macOS 的钥匙串里。
  • 不保存历史记录，不收集任何数据；翻译和润色的请求只发往你选择的服务商。
  • 截图在本机用 Apple 的 Vision 识别，图片不会离开你的 Mac。原处翻译只读取应用提供的文字，不截取屏幕画面。
